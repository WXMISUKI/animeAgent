## 📊 当前项目痛点分析

| 痛点类型 | 具体表现 | 严重程度 |
|---------|---------|---------|
| 无记忆机制 | 每次对话都是全新开始，无法实现多轮对话 | 🔴 高 |
| 意图理解弱 | 仅基础关键词匹配，无槽位提取/纠错/泛化 | 🔴 高 |
| 规划能力弱 | 简单工具调用，无多步规划/优先级策略 | 🟠 中 |
| 无容错机制 | 数据源调用失败无重试/熔断/降级 | 🟠 中 |
| 工程化不足 | 无容器化/监控/测试体系 | 🟡 中低 |
| 架构耦合 | 未分层，API/业务/数据混在一起 | 🟡 中低 |
| 流式体验差 | 流式输出无分块/状态提示 | 🟡 中低 |

## 📌 关键技术点

### 1. 短期记忆实现（Redis）

```python
# src/infrastructure/cache/redis_cache.py
import redis
from typing import Optional
import json

class RedisCache:
    def __init__(self, redis_url: str = "redis://localhost:6379/0"):
        self.client = redis.from_url(redis_url)
    
    def get_session(self, session_id: str) -> Optional[dict]:
        key = f"session:{session_id}"
        data = self.client.get(key)
        return json.loads(data) if data else None
    
    def set_session(self, session_id: str, context: dict, ttl: int = 86400):
        key = f"session:{session_id}"
        self.client.setex(key, ttl, json.dumps(context, ensure_ascii=False))
```

# src/data_sources/router.py - 增强容错
async def fetch_with_timeout(source, timeout=3, retries=2):
    for attempt in range(retries):
        try:
            return await asyncio.wait_for(source.search(params), timeout=timeout)
        except asyncio.TimeoutError:
            if attempt == retries - 1:
                logger.warning(f"{source.NAME} 查询超时，已达最大重试次数")
                return []
            await asyncio.sleep(1)  # 重试间隔
        except Exception as e:
            logger.error(f"{source.NAME} 查询失败: {e}")
            return []
