以下是全网可调用的开源番剧 / 二次元资讯 / 数据接口，覆盖资讯、番剧信息、角色、榜单、新闻等场景，均免费开源、可直接接入。
一、综合番剧 / 二次元数据接口（含资讯）
1. Jikan API（最主流、数据最全）
定位：非官方 MyAnimeList（MAL）开源 API，全球最活跃的动漫数据库之一
开源协议：MIT License，完全免费、无认证、可自建服务
核心能力：
番剧 / 漫画详情、评分、角色、声优、制作公司
新番 / 季度番剧、排行榜、推荐、评论、新闻
高级搜索、随机番剧、类型筛选
地址：https://jikan.moe/ | GitHub：https://github.com/jikan-me/jikan
示例：GET https://api.jikan.moe/v4/anime/1（获取《钢之炼金术师》信息）
2. Bangumi API（中文社区首选）
定位：Bangumi.tv 官方开放 API，中文二次元数据最全
开源：RESTful、社区驱动、持续更新
核心能力：
番剧 / 动画 / 漫画 / 游戏 / 轻小说全品类数据
新番时间表、评分、标签、用户收藏、评论、资讯
中文友好、支持简体 / 繁体
地址：https://bangumi.github.io/api/ | 文档：https://bangumi.github.io/api/
示例：GET https://api.bgm.tv/v0/subjects/1（获取《凉宫春日》信息）
3. AniList GraphQL API（现代、强查询）
定位：AniList 官方 GraphQL API，适合复杂数据查询
开源：免费、无密钥、支持 CORS
核心能力：
番剧 / 漫画 / 角色 /staff 全量数据
新番、 airing 状态、评分、标签、推荐、新闻
支持自定义字段、批量查询、分页
地址：https://anilist.gitbook.io/anilist-apiv2-docs/ | 端点：https://graphql.anilist.co
4. HibiAPI（聚合型、多源整合）
定位：开源聚合 API，整合 Bangumi、MAL、B 站等多源数据
开源：Python+Flask、MIT License、可自建
核心能力：
番剧信息、角色、音乐、新番、资讯、排行榜
统一接口、简化多源调用
地址：https://github.com/mixmoe/HibiAPI
二、专注二次元新闻 / 资讯接口
1. AniNewsAPI（实时新闻聚合）
定位：开源实时动漫新闻 API，抓取 Crunchyroll、ANN、MAL 等源
开源：MIT License、支持缓存、标签过滤、全文内容
核心能力：
最新动漫新闻、公告、新番情报、业界动态
按来源 / 时间 / 标签筛选
地址：https://github.com/Shineii86/AniNewsAPI
2. Anime News Network (ANN) API（权威业界新闻）
定位：老牌权威动漫新闻网站的 API
开源：免费、有 Python 封装库
核心能力：
业界新闻、新番宣布、制作消息、访谈、评论
分类新闻、时间线
地址：https://www.animenewsnetwork.com/news/api | Python 库：https://github.com/Nekmo/anime-news-network
三、其他实用开源二次元接口
1. Consumet API（聚合 + 流媒体 + 资讯）
定位：现代开源聚合 API，覆盖动漫、漫画、轻小说、影视
开源：TypeScript、MIT License、支持自建
核心能力：
番剧信息、新番、资讯、搜索、推荐
部分源含流媒体链接（合规使用）
地址：https://github.com/consumet/api.consumet.org
2. Kitsu API（社区驱动、多语言）
定位：开源动漫数据库 API，支持多语言
开源：免费、RESTful、无认证
核心能力：
番剧 / 漫画 / 游戏数据、新番、排行榜、资讯
地址：https://kitsu.docs.apiary.io/
四、接口对比（快速选型）
表格
接口	语言	核心优势	资讯能力	适合场景
Jikan	多语言	数据最全、全球覆盖、无认证	强（MAL 新闻）	全球番剧应用、工具
Bangumi	中文	中文社区、数据精准、新番全	强（Bangumi 资讯）	中文二次元项目
AniList	GraphQL	灵活查询、现代、社区活跃	中	复杂数据需求、Web 应用
AniNewsAPI	JS	纯新闻聚合、实时、多源	极强	新闻类 App、推送
ANN	多语言	权威业界新闻、老牌	极强	业界资讯、深度内容
五、使用建议
优先选 Jikan / Bangumi：覆盖 90% 番剧 / 资讯需求，文档完善、社区活跃。
新闻需求选 AniNewsAPI / ANN：专注资讯、更新快、来源权威。
自建部署：所有接口均开源，可自行部署避免公共节点限流。
合规提示：仅用于非商业 / 个人项目，遵守各源的 robots.txt 与使用条款。
