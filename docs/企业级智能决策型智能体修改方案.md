番剧智能体企业级整改方案与业界开发规范文档
一、文档概述
本文档基于当前番剧智能体项目现状，结合业界成熟的智能体开发流程与企业级架构标准，从技术选型优化、架构重构、功能增强、工程化规范四个维度提出整改方案，并梳理完整的智能体开发流程与核心功能设计规范，旨在将现有项目从 “基础工具调用型智能体” 升级为 “企业级智能决策型智能体”。

# src/core/exceptions.py
from fastapi import HTTPException, status

class AnimeAgentException(HTTPException):
    def __init__(self, detail: str, status_code: int = status.HTTP_500_INTERNAL_SERVER_ERROR):
        super().__init__(status_code=status_code, detail=detail)

class DataSourceException(AnimeAgentException):
    def __init__(self, detail: str):
        super().__init__(detail=detail, status_code=status.HTTP_503_SERVICE_UNAVAILABLE)

# src/api/dependencies.py
from fastapi import Request
from starlette.responses import JSONResponse

async def global_exception_handler(request: Request, exc: Exception):
    if isinstance(exc, AnimeAgentException):
        return JSONResponse(
            status_code=exc.status_code,
            content={"code": exc.status_code, "message": exc.detail, "data": None}
        )
    # 未知异常
    return JSONResponse(
        status_code=status.HTTP_500_INTERNAL_SERVER_ERROR,
        content={"code": 500, "message": "服务器内部错误", "data": None}
    )

2. 规划执行功能设计
2.1 执行计划生成规则
单意图：直接调用对应工具（如 ANIME_DETAIL→调用 get_anime_detail）
复合意图：拆分多步执行（如 “推荐热血番并获取评分”→推荐工具→详情工具）
优先级规则：精准数据源优先、缓存优先、异步执行非核心步骤
2.2 工具调用规范
工具入参：必须通过 Pydantic 校验
工具出参：统一返回结构化数据（AnimeInfo 模型）
超时控制：所有数据源调用超时≤3s
重试策略：失败重试 2 次，间隔 1s
