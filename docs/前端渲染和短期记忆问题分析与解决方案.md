## 一、问题概述

根据用户测试反馈，当前番剧智能体存在以下两个核心问题：

1. **前端 Markdown 列表渲染问题**：列表项（`<li>`）内容换行时，列表点无法对齐
2. **短期记忆功能失效**：多轮对话中，智能体无法正确理解指代词（如"这些"、"那部"），重复执行工具调用

---

## 二、问题一：前端 Markdown 列表渲染问题

### 2.1 问题描述

当 AI 回复中的列表项内容超过一行需要换行时，列表点（bullet point）无法正确对齐。

**示例**：
```
• 番剧名称：进击的巨人
• 番剧名称：鬼灭之刃 刀匠村篇
  （此处列表点应该对齐，但实际没有）
```

### 2.2 根本原因

当前 CSS 使用默认的 `list-style-type: disc`，列表点的位置由浏览器默认渲染决定。当内容换行时，不同浏览器的渲染行为不一致。

**当前 CSS**（`styles.css`）：
```css
.content-area ul {
    list-style-type: disc;
    padding-left: 24px;
}

.content-area li {
    margin: 2px 0;
    padding-left: 4px;
    word-wrap: break-word;
}
```

### 2.3 成熟智能体解决方案

参考 ChatGPT、Claude、DeepSeek 等成熟智能体的实现方式：

**方案 A：使用 `display: flex` + `::before` 伪元素（推荐）**

```css
.content-area ul {
    list-style: none;
    padding-left: 0;
    margin: 8px 0;
}

.content-area li {
    position: relative;
    padding-left: 24px;
    margin: 6px 0;
    line-height: 1.6;
}

.content-area li::before {
    content: "•";
    position: absolute;
    left: 8px;
    top: 0;
    color: #6366f1;
    font-size: 14px;
    line-height: 1.6;
}
```

**方案 B：使用 `list-style-position: outside`（简单）**

```css
.content-area ul {
    list-style: disc outside;
    padding-left: 24px;
    margin: 8px 0;
}

.content-area li {
    margin: 4px 0;
    padding-left: 4px;
    line-height: 1.6;
    text-indent: -4px;  /* 调整缩进 */
}
```

### 2.4 推荐实施方案

采用 **方案 A**，原因：
- ✅ 完全控制列表点的样式和位置
- ✅ 跨浏览器一致性更好
- ✅ 支持自定义列表点颜色和大小
- ✅ 便于后续扩展（如多级列表）

## 三、问题二：短期记忆功能失效

### 3.1 问题描述

**测试场景**：
1. 用户："推荐几部近期的日漫"
2. 智能体：返回日漫列表
3. 用户："这些番剧的评分怎么样？"
4. **问题**：智能体重新执行工具调用，查询排行榜，而不是查询刚才返回的日漫的评分

### 3.2 根本原因分析

通过代码审查，发现以下问题：

#### 问题 1：Checkpoint 状态未有效使用

**当前代码**（`src/agent/agent.py`）：
```python
# 从 checkpoint 恢复状态
checkpoint_state = None
if thread_id and self.enable_checkpoint and self.checkpoint_graph:
    try:
        config = {"configurable": {"thread_id": thread_id}}
        checkpoint_state = await self.checkpoint_graph.aget_state(config)
        if checkpoint_state:
            logger.info(f"📜 从 Checkpoint 恢复状态: thread_id={thread_id}")
    except Exception as e:
        logger.warning(f"从 Checkpoint 恢复状态失败: {e}")

# ❌ checkpoint_state 获取后没有被使用！
```

**问题**：虽然从 checkpoint 获取了状态，但后续的意图解析、参数提取等步骤完全没有使用这些状态。

#### 问题 2：上下文信息传递不完整

**当前代码**：
```python
# 获取会话上下文
context_text = ""
if session:
    context_text = session.get_context_text(max_turns)
    logger.info(f"📜 会话上下文: {len(context_text)} 字符")

# ❌ context_text 只传给了意图识别，没有传给参数提取
intent = await self.intent_parser._recognize_intent(user_input, context_text)
```

**问题**：
- `context_text` 只在意图识别时使用
- 参数提取（`_astream_extract_params`）没有使用上下文
- LLM 无法理解"这些"、"那部"等指代词

#### 问题 3：LangGraph Checkpoint 集成不完整

**当前实现**：
- ✅ Checkpoint 模块已创建
- ✅ 图编译时传入了 checkpointer
- ❌ 但 agent 执行流程是自定义的，没有使用 LangGraph 的 `ainvoke` 或 `astream`
- ❌ 状态的保存和恢复完全由手动代码实现，没有利用 LangGraph 的自动机制

### 3.3 成熟智能体解决方案

参考 ChatGPT、Claude 的多轮对话实现：

**核心机制**：
1. **完整的历史上下文传递**：每一步（意图识别、参数提取、工具执行）都有完整的历史上下文
2. **指代消解（Coreference Resolution）**：显式将历史信息格式化为可理解的上下文
3. **状态自动管理**：使用 LangGraph 的自动状态管理，而非手动实现

**示例上下文格式**：
```
历史对话：
用户: 推荐几部近期的日漫
助手: 我为你推荐以下几部近期日漫：
  1. 进击的巨人 最终季
  2. 鬼灭之刃 刀匠村篇
  3. 赛博朋克：边缘行者

当前问题: 这些番剧的评分怎么样？

请根据历史对话中的番剧名称，回答当前问题。
```

### 3.4 推荐实施方案

#### 方案 A：增强当前实现（快速修复）

**优点**：
- ✅ 改动最小
- ✅ 不需要重构整体架构
- ✅ 可以快速验证效果

**实施步骤**：

1. **在参数提取时传入上下文**
```python
# 在 run_streaming 方法中
params = {}
full_params_text = ""
async for param_chunk in self.intent_parser._astream_extract_params(
    user_input, 
    intent, 
    context_text  # ✅ 传入上下文
):
    full_params_text += param_chunk
    yield {"type": "intent", "status": "parsing", "params_delta": param_chunk}
```

2. **增强上下文格式化**
```python
def format_context_for_llm(context_text: str, recent_results: list) -> str:
    """格式化上下文供 LLM 理解指代词"""
    context_parts = ["历史对话:", context_text]
    
    if recent_results:
        context_parts.append("\n最近的查询结果:")
        for result in recent_results[-3:]:  # 最近3次结果
            if result.get("anime_results"):
                context_parts.append("- " + str(result["anime_results"][:3]))
    
    return "\n".join(context_parts)
```

3. **在 Prompt 中明确说明指代关系**
```python
prompt = f"""用户问题: {user_input}

## 上下文信息
{enhanced_context}

## 指代词说明
- "这些"、"这些番剧" -> 指上下文中最近的番剧查询结果
- "那部"、"那个" -> 指上下文中提到的某一部番剧
- "它们的" -> 指上下文中的某个集合

请根据上下文理解用户的真实意图。

只输出JSON格式："""
```

#### 方案 B：完全集成 LangGraph Checkpoint（长期方案）

**优点**：
- ✅ 完全利用 LangGraph 的自动状态管理
- ✅ 真正的断点恢复能力
- ✅ 架构更清晰，便于维护

**缺点**：
- ⚠️ 需要重构 agent 执行流程
- ⚠️ 改动较大，需要充分测试

**实施步骤**：

1. **重构 agent.py，使用 LangGraph 的 astream**
```python
async def run_streaming(self, user_input: str, thread_id: str = None, ...):
    # 使用 LangGraph 的自动状态管理
    config = {"configurable": {"thread_id": thread_id or str(uuid.uuid4())}}
    
    # 初始状态
    initial_state = {
        "messages": [HumanMessage(content=user_input)],
        "user_query": user_input,
        ...
    }
    
    # 使用 LangGraph 的 astream
    async for event in self.checkpoint_graph.astream(initial_state, config):
        # event 包含每个节点的状态变化
        if event["node"] == "classify_intent":
            yield {"type": "intent", ...}
        elif event["node"] == "execute_skill":
            yield {"type": "execution", ...}
        # ...
```

2. **在 state 中定义消息历史**
```python
class AgentState(TypedDict):
```

3. **在节点中访问历史消息**

2. **新增上下文格式化方法**

```python
def _format_enhanced_context(self, context_text: str, recent_results: list = None) -> str:
    """格式化增强的上下文，包含历史对话和查询结果"""
    parts = []
    
    # 1. 历史对话
    if context_text:
        parts.append("## 历史对话")
        parts.append(context_text)
    
    # 2. 最近的查询结果（用于指代消解）
    if recent_results:
        parts.append("\n## 最近的查询结果")
        for i, result in enumerate(recent_results[-2:], 1):  # 最近2次结果
            if result.get("anime_results"):
                parts.append(f"\n查询 {i}:")
                for anime in result["anime_results"][:3]:  # 最多3部
                    parts.append(f"  - {anime.get('name', '未知')}: {anime.get('rating', 'N/A')}")
    
    # 3. 指代词说明
    parts.append("\n## 指代词说明")
    parts.append("- '这些'、'这些番剧' → 指最近的查询结果中的番剧")
    parts.append("- '那部'、'那个' → 指历史对话中提到的某一部番剧")
    
    return "\n".join(parts)
```
