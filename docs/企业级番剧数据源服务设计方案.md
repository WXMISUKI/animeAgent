### 1.2 问题根因分析

**问题 1：意图解析失败**
- 现象：`params: {}` 空字典
- 可能原因：
  1. LLM 未能正确理解参数提取 prompt
  2. prompt 中强调的规则未被遵循
  3. JSON 解析失败

**问题 2：工具调用参数错误**
- 现象：`anime_type: 'all'` 而不是 `'国漫'`
- 可能原因：
  1. 意图解析返回的参数没有正确传递到工具
  2. 默认值覆盖

**问题 3：Bilibili 国漫搜索返回 0 条**
- 可能原因：
  1. API 接口调用方式不正确
  2. 搜索关键词不够准确
  3. API 响应数据结构理解错误

## 三、解决方案

### 3.1 短期方案（立即修复 P0 问题）

#### 方案 A：简化意图解析，绕过 LLM

**核心思路**：不依赖 LLM 提取参数，直接使用规则匹配 + 关键词检测

```python
def _quick_extract_params(user_input: str) -> dict:
    """快速提取参数 - 基于规则匹配"""
    params = {
        "anime_type": "all",
        "sort_by": "rating"
    }
    
    # 检测国漫
    if any(kw in user_input for kw in ["国漫", "国产", "国创"]):
        params["anime_type"] = "国漫"
    
    # 检测日漫
    if any(kw in user_input for kw in ["日漫", "日本动画"]):
        params["anime_type"] = "日漫"
    
    # 检测剧场版
    if any(kw in user_input for kw in ["剧场版", "电影版"]):
        params["anime_type"] = "剧场版"
    
    return params
```

#### 方案 B：强制参数校验

**核心思路**：在工具调用前，强制从用户输入中重新提取关键参数

```python
def _validate_and_fix_params(user_input: str, params: dict) -> dict:
    """校验并修复参数"""
    # 如果 anime_type 为空，从输入中检测
    if params.get("anime_type") in [None, "all", ""]:
        if "国漫" in user_input or "国产" in user_input:
            params["anime_type"] = "国漫"
        elif "日漫" in user_input:
            params["anime_type"] = "日漫"
        elif "剧场版" in user_input or "电影" in user_input:
            params["anime_type"] = "剧场版"
    
    return params
```
